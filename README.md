# دفتري الدراسي — منصة تعليمية شخصية

موقع ثابت (Static) بالكامل، مبني بـ HTML/CSS/JS بدون أي مكتبات أو أدوات بناء، يعمل مباشرة على GitHub Pages.

## هيكل الملفات

```
edu-platform/
├── index.html          ← الصفحة الرئيسية (واجهة الطالب)
├── css/style.css        ← التصميم
├── js/app.js             ← كل منطق التطبيق
├── data/
│   ├── manifest.json     ← قائمة السنوات الدراسية المتاحة
│   └── years/
│       └── year-1.json   ← بيانات كل سنة (مواد ← دروس ← شرح/مراجعة/تقييم)
└── admin/                ← (اختياري) مكان لأداة تأليف محلية أشمل لاحقًا
```

## طريقة تشغيل الموقع محليًا

بما إن الموقع بيحمّل ملفات JSON عن طريق `fetch`، المتصفح مش هيسمح بيه لو فتحت `index.html` مباشرة (file://). لازم سيرفر محلي بسيط:

```bash
cd edu-platform
python3 -m http.server 8000
```

بعدين افتح: `http://localhost:8000`

## رفعه على GitHub Pages

1. ارفع محتويات المجلد كامل لريبو على GitHub.
2. من إعدادات الريبو → Pages → اختر الفرع (main) والمجلد (root).
3. هيبقى الموقع شغّال على رابط GitHub Pages تلقائيًا.

## إدارة المنصة بدون أي برمجة (وضع الأدمن)

فعّل مفتاح **"وضع الأدمن"** أعلى الشريط الجانبي. بعدها هيظهر لك:

- **إضافة/تعديل/حذف سنة دراسية**: زرار "+ سنة دراسية جديدة" أعلى الشريط الجانبي، وأيقونات ✎ (تعديل) و🗑 (حذف) جنب كل سنة.
- **إضافة/تعديل/حذف مادة دراسية**: زرار "+ مادة جديدة" جوه كل سنة، مع اختيار اسم ولون مميز للمادة.
- **إضافة/تعديل/حذف درس**: من داخل صفحة المادة، زرار "+ إضافة درس جديد" بيفتح نموذج كامل لكتابة:
  - نص الشرح + رابط فيديو/صوت (اختياري)
  - نص المراجعة + أسئلة مراجعة ذاتية (تضيف/تحذف سؤال بزرار)
  - أسئلة الاختبار (اختيار من متعدد) — تضيف سؤال، تضيف/تحذف اختيارات، وتحدد الإجابة الصحيحة بالدائرة جنبها.

كله بنماذج وأزرار عادية، من غير أي كود أو JSON يدوي.

### إزاي البيانات بتتخزن؟

كل تعديل (سنة/مادة/درس) بيتحفظ فورًا في متصفحك (`localStorage`) — يعني المنصة شغالة وبتفضل متذكرة كل حاجة حتى لو قفلت المتصفح أو رجعت تاني يوم، من غير ما تحتاج ترفع أي حاجة على GitHub.

⚠️ التخزين ده مرتبط بالمتصفح والجهاز. لو فتحت المنصة من متصفح أو جهاز تاني، أو مسحت بيانات المتصفح، مش هتلاقي تعديلاتك. عشان كده فيه صفحة **"💾 البيانات والنسخ الاحتياطي"** في أسفل الشريط الجانبي فيها:

- **تنزيل نسخة احتياطية**: ملف JSON واحد فيه كل بياناتك، تقدر تحتفظ بيه أو تنقله لجهاز/متصفح تاني.
- **استعادة من نسخة احتياطية**: ترفع نفس الملف ده في متصفح/جهاز تاني عشان تسترجع كل حاجة.
- **مسح نتائج الاختبارات**: يمسح سجل النتائج بس.
- **استعادة البيانات الافتراضية**: يمسح كل تعديلاتك ويرجّع البيانات الأصلية من ملفات المشروع (`data/years/*.json`) — استخدمها بحذر.

### (اختياري متقدم) تثبيت التعديلات في ملفات المشروع على GitHub

لو حابب تعديلاتك تبقى هي "النسخة الافتراضية" للموقع على GitHub Pages نفسه (مش بس في متصفحك):
1. من صفحة "البيانات والنسخ الاحتياطي" نزّل نسخة احتياطية.
2. افتح الملف، وانسخ بيانات كل سنة على حدة إلى ملف `data/years/<اسم-السنة>.json` المقابل لها (أو أنشئ ملف جديد وضيفه في `data/manifest.json`).
3. ارفع (commit) الملفات المعدّلة على GitHub.

الخطوة دي اختيارية تمامًا وغير ضرورية للاستخدام اليومي.

## شكل بيانات الدرس (JSON)

```json
{
  "id": "math-l1",
  "title": "الأعداد الصحيحة",
  "explanation": { "text": "...", "audioUrl": "", "videoUrl": "" },
  "review": { "text": "...", "questions": ["سؤال 1", "سؤال 2"] },
  "test": {
    "durationMinutes": 10,
    "questions": [
      { "id": "q1", "type": "mcq", "question": "...", "options": ["أ","ب","ج","د"], "correctIndex": 2 }
    ]
  }
}
```

- `audioUrl` / `videoUrl`: لو عندك ملف صوت/فيديو، ارفعه في مجلد زي `media/` واكتب المسار هنا (أو رابط خارجي زي YouTube embed مباشر).
- النتائج بتتخزن في `localStorage` تحت مفتاح `dafatri_results` وتظهر في صفحة "نتائجي".

## توسيع الموقع

- **إضافة سنة دراسية جديدة**: أنشئ ملف `data/years/year-2.json` بنفس البنية، وضيفه في `data/manifest.json`.
- **إضافة مادة**: ضيف عنصر جديد في مصفوفة `subjects` داخل ملف السنة.
- **أنواع أسئلة أخرى** (مقالي مثلًا): تقدر تضيف `"type": "text"` وتعدّل منطق `renderQuiz` في `app.js` ليدعمها.

## حماية وضع الأدمن بكلمة مرور

أول مرة تفعّل فيها "وضع الأدمن" هيُطلب منك تحديد كلمة مرور. بعد كده، هتُطلب منك كلمة المرور دي في بداية كل جلسة تحاول فيها تفعّل الوضع (الوضع بيتقفل تلقائيًا لما تعمل تحديث للصفحة أو تقفل المتصفح). من صفحة "البيانات والنسخ الاحتياطي" تقدر تغيّر كلمة المرور أو تلغيها تمامًا.

⚠️ ملاحظة: بما إن الموقع Static بالكامل (مفيش سيرفر)، الحماية دي بتمنع الاستخدام العرضي أو من شخص عادي بيفتح الموقع، لكنها مش حماية أمنية بمعنى "قوية" ضد شخص عنده خبرة تقنية وبيفتح أدوات المطوّر في المتصفح.

## الوضع الداكن والفاتح

فيه زرار (🌙 / ☀️) جنب اسم المنصة في أعلى الشريط الجانبي لتبديل الوضع الداكن/الفاتح. الاختيار بيتحفظ تلقائيًا ويفضل زي ما هو في المرات الجاية.

## التوافق مع الشاشات المختلفة

على الشاشات الصغيرة (موبايل/تابلت) بيختفي الشريط الجانبي ويتحول لقائمة منسدلة تفتح بزرار ☰ أعلى الصفحة، والتبويبات والجداول بتتصرف عشان تفضل قابلة للاستخدام بسهولة على أي حجم شاشة.
