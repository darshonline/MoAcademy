# دفتري الدراسي — منصة تعليمية شخصية

موقع ثابت (Static) بالكامل، مبني بـ HTML/CSS/JS بدون أي أدوات بناء، يعمل على GitHub Pages، ومتصل بقاعدة بيانات [Supabase](https://supabase.com) مجانية عشان كل البيانات تتزامن فورًا بين أي جهاز أو متصفح.

## هيكل الملفات

```
edu-platform/
├── index.html            ← الصفحة الرئيسية (واجهة الطالب والأدمن)
├── css/style.css          ← التصميم (وضع داكن/فاتح + تجاوب مع الشاشات)
├── js/
│   ├── config.js           ← بيانات الاتصال بمشروع Supabase بتاعك (تعبّيها بنفسك)
│   └── app.js               ← كل منطق التطبيق
├── data/
│   ├── manifest.json        ← بيانات تجريبية أولية (تُستخدم للبذر الأول لـ Supabase فقط)
│   └── years/year-1.json
└── supabase-setup.sql     ← كود SQL تشغّله مرة واحدة في مشروع Supabase بتاعك
```

## الإعداد الأول: ربط المنصة بـ Supabase (خطوة لازمة قبل أي حاجة)

### 1. أنشئ مشروع Supabase مجاني
روح على [supabase.com](https://supabase.com)، اعمل حساب مجاني، وأنشئ مشروع جديد.

### 2. جهّز الجداول
من لوحة تحكم المشروع: **SQL Editor → New query**. انسخ كل محتوى ملف `supabase-setup.sql` والصقه وشغّله (Run). ده بيعمل جدول لبيانات المنصة وجدول لنتائج الاختبارات، مع صلاحيات مناسبة (RLS).

### 3. اعمل حساب الأدمن بتاعك
من القائمة الجانبية: **Authentication → Users → Add user**. حط إيميل وكلمة مرور، وفعّل **Auto Confirm User** عشان الحساب يشتغل على طول.

### 4. هات بيانات الاتصال
من **Project Settings → API** هتلاقي **Project URL** و **anon public key**.

### 5. حطهم في المشروع
افتح `js/config.js` واستبدل القيمتين:
```js
const SUPABASE_URL = 'https://xxxxxxxx.supabase.co';
const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
```
ثم ارفع (commit) التعديل على GitHub.

### 6. حمّل بيانات تجريبية لأول مرة (اختياري)
افتح الموقع، فعّل وضع الأدمن وسجّل دخول بالحساب اللي عملته، وبعدين من صفحة "💾 البيانات والنسخ الاحتياطي" دوس **"استعادة البيانات الافتراضية"** — أو سيبها فاضية وابدأ تضيف بنفسك.

بعد كده أي جهاز يفتح رابط الموقع هيشوف نفس البيانات بالظبط، لحظة بلحظة.

## طريقة تشغيل الموقع محليًا

```bash
cd edu-platform
python3 -m http.server 8000
```
بعدين افتح: `http://localhost:8000`

## رفعه على GitHub Pages

1. تأكد إنك ملأت `js/config.js` ببيانات Supabase بتاعتك.
2. ارفع محتويات المجلد كامل لريبو على GitHub.
3. من إعدادات الريبو → Pages → اختر الفرع (main) والمجلد (root).

## إدارة المنصة بدون أي برمجة (وضع الأدمن)

فعّل مفتاح **"وضع الأدمن"** أعلى الشريط الجانبي، وسجّل دخول بالإيميل وكلمة المرور اللي عملتهم في Supabase. بعدها هيظهر لك:

- **إضافة/تعديل/حذف سنة دراسية**: زرار "+ سنة دراسية جديدة" أعلى الشريط الجانبي، وأيقونات ✎ (تعديل) و🗑 (حذف) جنب كل سنة.
- **إضافة/تعديل/حذف مادة دراسية**: زرار "+ مادة جديدة" جوه كل سنة، مع اسم ولون مميز للمادة.
- **إضافة/تعديل/حذف درس**: زرار "+ إضافة درس جديد" بيفتح نموذج كامل لكتابة الشرح، المراجعة، وأسئلة الاختبار.

كله بنماذج وأزرار عادية، من غير أي كود أو JSON يدوي.

## المزامنة بين الأجهزة

كل تعديل بيتبعت فورًا لقاعدة بيانات Supabase، مش لمتصفحك بس. تفتح الموقع من أي جهاز، هتشوف نفس البيانات بالظبط. وتسجيل الدخول كأدمن بنفس الإيميل وكلمة المرور من أي جهاز.

## حماية وضع الأدمن

الدخول لوضع الأدمن بيتطلب تسجيل دخول حقيقي (Supabase Auth) بإيميل وكلمة مرور، مش مجرد كود محلي. الجلسة بتفضل شغالة على نفس الجهاز/المتصفح لحد ما تعمل "تسجيل الخروج" (من صفحة الإعدادات) أو تدخل من جهاز جديد يحتاج تسجيل دخول مستقل.

## صفحة "البيانات والنسخ الاحتياطي"

- **تنزيل / استعادة نسخة احتياطية**: ملف JSON واحد فيه كل بياناتك.
- **مسح نتائج الاختبارات**.
- **تغيير كلمة مرور الأدمن** (تُستخدم من أي جهاز فورًا).
- **استعادة البيانات الافتراضية**: يمسح كل تعديلاتك ويرجّع البيانات التجريبية الأصلية — استخدمها بحذر.

## الوضع الداكن والفاتح

زرار (🌙 / ☀️) جنب اسم المنصة أعلى الشريط الجانبي. الاختيار بيتحفظ في المتصفح ويفضل زي ما هو في المرات الجاية.

## التوافق مع الشاشات المختلفة

على الشاشات الصغيرة (موبايل/تابلت) بيختفي الشريط الجانبي ويتحول لقائمة منسدلة تفتح بزرار ☰ أعلى الصفحة، والتبويبات والجداول والمودالات كلها متكيفة مع أي حجم شاشة.

## توسيع الموقع

- **إضافة سنة/مادة/درس**: كله من واجهة وضع الأدمن، من غير تعديل ملفات.
- **أنواع أسئلة أخرى** (مقالي مثلًا): يحتاج تعديل بسيط في منطق `renderQuiz` و`openLessonModal` داخل `js/app.js`.
